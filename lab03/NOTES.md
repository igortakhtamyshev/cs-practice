Команда git show показывает подробную информацию об объекте Git (коммите, теге или файле), включая автора, дату, сообщение и изменения в виде diff-разницы.
Команда git diff показывает точные построчные различия (diff) между разными состояниями репозитория — добавленные, удаленные и измененные строки.
Команда git log показывает историю коммитов (сохранений) в текущем репозитории. 
Команда git blame показывает для каждой строки файла, кто, когда и в каком коммите изменил её последним.
git restore <file> Возвращает файл к состоянию из последнего коммита (или индекса), уничтожая несохраненные правки в рабочей зоне.
git restore --source=<commit> <file> Заменяет текущую версию файла на версию из указанного коммита.
