«Ветки»
Ветка в Git — это легкий и подвижный указатель на конкретный коммит в истории проекта.Что происходит с веткой при новом коммите. Сдвиг указателя: Когда вы создаете новый коммит, указатeль 
текущей активной ветки автоматически перемещается вперед на этот новый коммит.Сохранение родителя: Новый коммит получает ссылку на свой родительский коммит, продолжая цепочку истории.Остальные 
ветки на месте: Другие ветки не двигаются и продолжают указывать на те коммиты, где они находились до этого.Что делает слияние (git merge)Слияние объединяет историю и изменения из одной ветки в другую.
 Оно работает двумя основными способами:Fast-forward (Перемотка вперед): Если в основной ветке не было новых коммитов с момента создания ответвления, Git просто передвигает указатель основной ветки вперед 
на последний коммит дочерней ветки. Новый промежуточный коммит не создается.Трехстороннее слияние (Three-way merge): Если истории обеих веток разошлись (в обеих есть новые коммиты), Git находит их общего предка,
 сравнивает изменения и создает новый коммит слияния (merge-коммит), у которого сразу два родителя. Если одни и те же строки были изменены по-разному, возникает конфликт, который нужно решить вручную.
